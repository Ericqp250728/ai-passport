# 摊主胸牌（Stall Badge）

摊主胸牌把 AI Passport 变成挂在胸前的招牌，适合市集摆摊、快闪店和接单服务。
它显示店名和卖点，长按一下就亮出收款码，还会记下本场卖出的东西。账本掉电不丢。

![电脑上渲染的四个页面：招牌、收款、记一笔、本场账本](../assets/images/stall-badge-preview.png)

截图由 `tools/badge_preview.py` 生成。它在电脑上运行真实的 `main/badge_ui.c`，
并套用与设备相同的圆角遮罩。设备上的实际显示效果仍需上机确认。

## 页面与按键

四个页面按以下顺序循环：招牌 → 收款 → 记一笔 → 本场账本。

| 按键 | 招牌 | 收款 | 记一笔 | 账本 |
| --- | --- | --- | --- | --- |
| OK 短按 | 下一页 | 下一页 | 下一页 | 下一页 |
| OK 长按 | 直接亮出收款码 | 回到招牌 | **记一笔（选中的商品）** | **撤销上一笔** |
| 上 / 下 短按 | 调亮 / 调暗 | 切换收款码 | 移动选中项 | — |
| 下 长按 | — | — | — | 第一次进入待确认，3 秒内再长按一次才清零 |

自动行为：

- 账本页闲置 15 秒后回到招牌，免得顾客看到你的营业额。
- 收款页始终全亮，方便扫码；闲置 120 秒后回到招牌。
- 其他页面闲置 60 秒后背光降到 10%。调暗后按下的第一下只负责唤醒屏幕。
- 记账成功是上行的"叮咚"，撤销是下行两声，出错或清零是低音。
  声音是可选的：音频初始化失败时胸牌照常工作，只是没有声音。
- 右上角显示电量；读不到电量计时隐藏，不显示假数字。

设备没有联网校时，所以账本按"本场"而不是按天统计。它保存每种商品的合计，
并保留最近 32 笔供撤销。收摊时清零即可。

## 换成你自己的店

1. 把 `main/badge_content.c` 复制为 `main/badge_content_local.c`，然后修改副本。
   Git 会忽略这个本地文件，你的收款码不会被提交。只要本地文件存在，构建就会用它。
2. 取出收款码里的文字。用任意扫码工具扫你的微信或支付宝收款码，把解出来的文字
   （通常以 `wxp://` 或 `https://qr.alipay.com/` 开头）粘贴到 `payload`。
   含有 `example.com` 的内容会被当作示例占位，上面会盖一条红色的"示例码"横带，
   防止顾客扫到假链接付款。
3. 价格按"分"填写（`2500` 表示 ¥25）。最多支持 8 种商品、4 行卖点、2 个收款码。
   每行卖点建议不超过 8 个汉字，店名不超过 7 个汉字；超长部分显示省略号。
4. 重新生成字库。固件只编入用到的字，不重新生成的话新字会显示成方框：

   ```bash
   python3 tools/gen_badge_fonts.py          # 需要 Node.js，首次会下载思源黑体（Noto Sans SC）
   python3 tools/gen_badge_fonts.py --check  # 只检查覆盖情况，validate.sh 也会运行它
   ```

5. 烧录前可以先在电脑上预览页面（可选）：

   ```bash
   python3 tools/badge_preview.py            # 输出 build/badge-preview/*.png
   ```

   这需要第一次 `idf.py build` 下载到 `managed_components/` 的 LVGL 源码，
   或者用 `--lvgl` 指定一份 LVGL 9.5 源码。

6. 照常构建、烧录（见[构建与测试](development/engineering/build-and-test.zh_CN.md)）。

## 怎么用它

固件本身不会赚钱。它的作用是在你本来就在卖东西的场合，帮你省时间、显得专业：

- **市集和夜市摆摊。** 招牌负责吸引人，长按一下亮出收款码，收摊时账本告诉你卖了什么。
- **快闪店、校园义卖和公益市集。** 几位帮手各戴一块，最后对一下各自的本场合计。
- **摄影、美甲、维修、家教等接单服务。** 列出服务和价格，当场收款。
- **给别人定制固件。** 同样的结构可以改成活动胸牌、店铺胸牌或礼物。内容集中在一个文件里，
  字库和预览都能自动生成，换一套设计主要只改 `badge_ui.c`。

## 文件

| 路径 | 作用 |
| --- | --- |
| `main/main.c` | 启动、按键队列、应用任务、电量轮询和各项动作 |
| `main/badge_nav.c` | 纯逻辑的页面与按键状态机，含闲置超时和清零确认（有主机测试） |
| `main/badge_ledger.c` | 纯逻辑的本场账本：记账、撤销，以及带版本和校验和的 NVS 数据块（有主机测试） |
| `main/badge_fmt.c` | 金额格式化与占位码识别（有主机测试） |
| `main/badge_ui.c` | LVGL 页面；只能在持有 `bsp_lvgl_lock()` 时调用 |
| `main/badge_store.c` | NVS 命名空间 `badge`：`ledger` 数据块和 `bright` 亮度档位 |
| `main/badge_sfx.c` | 合成提示音，在独立任务里播放 |
| `main/badge_content.c` | 示例内容；你的 `badge_content_local.c` 会替代它 |
| `assets/fonts/badge_*.c` | 生成的思源黑体子集，字符清单在 `badge_glyphs.txt` |
| `tools/gen_badge_fonts.py` | 字库生成与覆盖检查 |
| `tools/badge_preview.py` | 在电脑上渲染页面 |

基线的硬件测试页面（`main/demo_*.c`、`main/ui_pixel*.c`）为了保留它们的主机测试仍在仓库中，
但已不再编进固件，开机直接进入胸牌。

## 资源预算

- LVGL 内存池由 24 KB 调到 32 KB，因为 196 px 的收款二维码画布要占用约 5 KB。
  主机预览报告的最高池占用为 64%（收款页，64 位指针），设备上会更低。
- 静态 DRAM 约用 116 KB / 321 KB。应用镜像约 0.8 MB，8 MB 应用分区约 90% 空闲。
- 每次记账、撤销或清零后，NVS 写入一个 256 字节的账本数据块。
